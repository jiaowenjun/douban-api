## 一、Intro 字段结构

音乐 intro 为豆瓣收藏列表页元数据行，字段以 ` / ` 分隔，典型顺序：

```
表演者（别名以逗号相连） / 发行日期 / 专辑形态（专辑/单曲/EP…） / 介质（CD/黑胶…） / 流派
```
示例（《歌之女》）：

```
梅艷芳,Anita Mui / 1995-8-1 / 专辑 / CD / 流行
```

部分条目缺“专辑形态”字段（如《Chopin: Preludes…》只有 4 段），解析按字段内容归类而非固定位置。
